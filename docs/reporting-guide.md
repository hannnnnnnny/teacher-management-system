# Reporting Guide

The Teacher Management System reports page helps administrators review finance, staffing, and academic performance.

## Payroll

Payroll totals are calculated from teacher salary records. The page shows:

- Total salary amount due.
- Payroll grouped by department.
- Detailed teacher salary list.

## Staffing Ratio

The student-to-teacher ratio compares the number of active student records with teacher records. This helps administrators understand whether staffing coverage is balanced.

## Academic Performance

The report page summarizes:

- Overall average score.
- Score distribution by performance level.
- Grade-level score averages.
- Class-level score averages with head teacher information.

## Teacher and Course Matching

The teacher-course matching report links each teacher with assigned courses and related classes. This helps identify teachers without assigned courses and classes that may need better coverage.

## Data Source

The current report view uses frontend demo records and backend seed data. When a real database is connected, the same report sections can be mapped to teacher, student, class, course, score, and resource tables.
